# Phase 2 — 基因长度归一化敏感性分析

**日期：** 2026-06-02  
**脚本：** `scripts/Phase2/validate_tp53_me_gene_length_sensitivity.R`  
**输出目录：** `analysis_results/Phase2/length_norm/`

---

## 背景与问题

Phase 2 跨队列验证发现 TRRAP 与 TP53 存在互斥信号（pooled OR = 0.348，p = 0.0017）。TRRAP 是测试基因中 CDS 最长的（11.6 kb），是 TP53（1.2 kb）的 9.8 倍。

**潜在混淆机制：**  
外显子组测序（WXS）中，基因越大，在相同 TMB 背景下随机积累体细胞突变的概率越高。EBV/MSI-H 肿瘤本身就是 TP53 野生型且高 TMB，因此大基因（如 TRRAP）会在这些肿瘤中随机富集突变，造成"伪互斥"。原模型中的 `log₂(TMB)` 协变量控制了整体突变负荷，但不能完全消除基因大小本身带来的靶区域优势。

## 三种模型定义

| 模型 | 预测变量 | 统计模型 |
|------|---------|---------|
| **A（原始）** | 基因 B 是否突变（0/1 二元变量） | `logit(TP53) ~ gene_B + log₂(TMB)` |
| **B（突变率）** | 功能性突变数 / 基因 CDS Mb | `logit(TP53) ~ mut_rate_B + log₂(TMB)` |
| **C（Poisson 残差）** | Pearson 残差：观测值 − 泊松零假设期望值 | `logit(TP53) ~ residual_B + log₂(TMB)` |

**模型 C 的零假设期望值：**

$$p_{\text{null},i} = 1 - \exp\!\left(-\text{TMB}_i \times \text{CDS\_Mb}_G\right)$$

该残差代表"在已知 TMB 和基因大小的条件下，超出随机预期的突变信号"。若 ME 信号在模型 C 中消失，说明原始信号可以被基因大小 × TMB 完全解释。

**队列范围：** 仅 WXS 队列（TCGA-STAD、TMUCIH 2015、OncoSG 2018、HK Pfizer）。IMPACT341 面板不覆盖 TRRAP，已排除。FDU 发现队列原始数据未在此脚本中加载，不重新分析。

## 各基因解读

### ARID1A — 信号最稳健

模型 C 校正后 OR 从 0.183 升至 0.836，但仍极显著（p = 6.1 × 10⁻⁷）。OR 的衰减是预期内的，因为 ARID1A（6.9 kb）比 TP53 大 5.8 倍，部分信号确实来自大基因效应。但剩余信号已足够强，基因长度不能解释 ARID1A–TP53 ME 的主体。

**文献背景：** TCGA 2014 胃癌分子分型论文中已明确记录，反映 EBV/MSI-H（ARID1A 富集）与 CIN 亚型（TP53 富集）的分子互斥。属于已知关系，在此作为方法学阳性对照。

### ATM — 信号稳健，胃癌中的新证据

模型 C 校正后 OR = 0.860，p = 0.031，仍显著。ATM CDS = 9.2 kb（TP53 的 7.8 倍），校正后 OR 从 0.427 升至 0.860，衰减幅度大于 CDH1，但信号未消失。更值得关注的是，三个 WXS 队列的 **I² = 0%**，即零异质性，说明这是一个跨人群一致的生物学信号。

**文献背景：** ATM–TP53 ME 在 CLL 和乳腺癌中已有系统记录，生物学机制明确（ATM 失活与 TP53 失活为两条平行的基因组不稳定路径）。**在胃癌中尚无经 TMB 校正、多队列验证的系统性文献记录，是本分析中潜在新贡献最高的发现。**

### CDH1 — 信号稳健，OR 衰减幅度最大

模型 C 校正后 OR = 0.958，p = 0.011。CDH1 CDS 仅 2.5 kb，相对 TP53 只大 2.1 倍，基因大小本不应造成明显混淆。OR 从 0.382 衰减至 0.958（比值 = 2.50×）幅度偏大，可能原因：MSK2017 队列在模型 B 中产生 I² = 46% 的异质性，提示 CDH1 在转移性队列（MSK）中的突变谱与原发肿瘤不同，带来额外方差。模型 C 的 I² = 0%，说明校正后方向一致，总体稳健。

**文献背景：** 反映 Lauren 分型中弥漫型（CDH1 突变，TP53 野生型）与肠型（TP53 突变）的经典分子分野。属于已知关系。

### TRRAP — 信号消失，降级处理

模型 C 校正后 OR = 0.919，p = 0.356，**不显著**。TRRAP CDS = 11.6 kb，为测试基因中最大，是 TP53 的 9.8 倍。Poisson 残差模型将"高 TMB × 大基因"期望值扣除后，信号完全消失。

**结论：** Phase 2 中的 TRRAP ME 信号（OR = 0.348，p = 0.0017）**很可能由基因长度与 TMB 的交互作用造成**，而非真实的生物学互斥。TRRAP 应从高置信候选基因名单中移除，或明确标注为"基因大小混淆未排除"。

注：TRRAP 不在 IMPACT341 面板上，仅 2 个 WXS 队列（TCGA + OncoSG）进入模型，样本量限制使本结论仍有不确定性，但方向明确。

### ARID2 — 两种模型均不显著

在 Phase 2 中已为 p = 0.073 的趋势，本次三种模型均未达显著。基因长度不是主要问题，更可能是统计功效不足（各队列突变频率低）。

## 局限性

1. **FDU 原始数据未重新分析**：FDU 发现队列的 Phase 1 结果为预计算值，无法在此框架下对 TRRAP 做长度校正。
2. **TRRAP 仅 2 个 WXS 队列**：TMUCIH 和 HK Pfizer 因 TRRAP 突变数 < 5 被排除，统计功效有限，不排除更大 WXS 数据集中信号恢复。
3. **CDS 长度使用典范转录本**：实际 WXS 捕获范围可能略有差异，但对结论影响有限。
4. **模型 B 的 OR 不可直接与模型 A 比较**：单位不同（每 Mb 突变率 vs. 二元变量），仅模型 C（Poisson 残差）与模型 A 具有可比的方向性解读。

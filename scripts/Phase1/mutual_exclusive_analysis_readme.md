## `somatic_interactions.R` — How mutual exclusivity is tested

### Method

`maftools::somaticInteractions()` runs a **Fisher's exact test** on every gene pair from a binary mutation matrix (1 = mutated in sample, 0 = not).

For each pair (Gene A, Gene B) the 2×2 contingency table is:

|  | B=0 | B=1 |
|---|---|---|
| **A=0** | neither | B only |
| **A=1** | A only | both |

- **Odds ratio < 1** → fewer double-mutants than expected → **Mutually Exclusive**
- **Odds ratio > 1** → more double-mutants than expected → **Co-occurring**
- Significance thresholds: p < 0.05 and p < 0.01 (used for plot color-coding)

Only functional variant classes are counted (missense, nonsense, frameshift, splice-site, in-frame indels, nonstop, translation-start-site). Silent mutations are excluded.

### Two runs

**Run A — Broad** (`interactions_broad_top50`): all pairwise tests among the top 50 most-frequently mutated genes. Gives an unbiased landscape view.

**Run B — Focused** (`interactions_focused`): seed genes (CDH1, TP53, APC, PIK3CA) plus any somatic panel gene that is a 1st-degree BioGRID interactor of **≥2 seeds** (from the Tier 3 Neo4j query). Reduces multiple-testing burden and focuses on biologically connected genes.

### Confounder-adjusted logistic regression

Fisher's exact test does not account for tumour-level covariates that confound mutation co-occurrence. For example, high-TMB tumours accumulate more mutations genome-wide, inflating apparent co-occurrence; MSI-H tumours and signet-ring histology have distinct mutation landscapes. The logistic regression step re-tests every gene pair from Run A after adjusting for these confounders.

#### Model

For each ordered gene pair (A, B), a binomial logistic regression is fitted:

$$\text{logit}\{P(A=1)\} = \beta_0 + \beta_1 B + \beta_2 \log_2(\text{TMB})$$

- **β₁** is the coefficient of interest: negative β₁ indicates mutual exclusivity between A and B after adjusting for TMB.
- Every pair is tested in **both directions** (A ~ B and B ~ A). For a genuine ME signal both directions should return β₁ < 0 with concordant p-values.

#### Covariate coding

| Covariate | Variable | Coding | Rationale |
|---|---|---|---|
| Tumour mutation burden | `TMB_report_numeric` | log₂(max(TMB, 0.1)) | Right-skewed; log-transform linearises the relationship; floored at 0.1 to avoid log(0) |

Samples missing TMB are excluded from the logistic regression.

#### Multiple testing

BH false-discovery rate correction is applied across all models within a run. With 2,450 models (broad top-50 pairs × 2 directions), the correction is stringent; p_adj < 0.05 is reported as the nominal threshold and FDR is shown alongside for interpretation.

#### Interpreting the tile plot (`interactions_broad_logistic.png`)

- **Red tiles**: OR_adj < 1 (mutually exclusive after confounder adjustment)
- **Blue tiles**: OR_adj > 1 (co-occurring after adjustment)
- **Colour intensity**: log₂(OR_adj), clamped to [−4, +4]
- **★ marker**: p_adj < 0.05
- Pairs where Fisher and logistic regression disagree in direction suggest confounder-driven artefact in the unadjusted test

## `query_seed_genes_neo4j.py` — Seed gene KB queries

Queries the local Neo4j knowledge graph (45k genes, BioGRID, Reactome, GO, UniProt) using CDH1 / TP53 / APC / PIK3CA as seeds. Five tiers:

| Tier | Query |
|---|---|
| 1 | Per-gene Reactome pathways, GO terms, UniProt function |
| 2 | Reactome pathways shared by ≥2 seeds |
| 3 | Somatic panel genes that are 1st-degree BioGRID interactors of any seed |
| 4 | Genes connecting to ≥2 seeds in BioGRID (CDH1/APC-anchored to filter TP53's large cloud) |
| 5 | Reactome protein-level interactions per seed |

Outputs go to `analysis_results/Phase1/neo4j_queries/`.

```bash
/home/sgao30/micromamba/bin/micromamba run -n ProjectGeneration \
    python3 scripts/Phase1/query_seed_genes_neo4j.py
```

## `run_deepseek_reasoning.py` — DeepSeek-R1 mechanistic interpretation

Sends a Markdown prompt file to DeepSeek-R1 (chain-of-thought) or DeepSeek-V3 and saves the response. Used for LLM-assisted mechanistic interpretation of analysis results.

```bash
# Default: DeepSeek-R1 with reasoning chain
python scripts/Phase1/run_deepseek_reasoning.py --input path/to/prompt.md

# Save outputs to a specific directory
python scripts/Phase1/run_deepseek_reasoning.py --input prompt.md --output-dir results/

# Use DeepSeek-V3 (no thinking chain)
python scripts/Phase1/run_deepseek_reasoning.py --input prompt.md --model deepseek-chat
```

Outputs written next to the prompt file (or to `--output-dir`):
- `<stem>_thinking.md` — internal reasoning chain (R1 only)
- `<stem>_response.md` — final answer

See `run_deepseek_reasoning_usage.md` for prompt examples and verification workflow.

> **Verification note**: LLM outputs must be cross-checked against PubMed before use.
> See memory note on DeepSeek verification workflow.
